# apps/sys

System commands expose guest identity, environment, clock, logging and shell entry points. Mutating commands enforce guest privileges and update kernel or session state through Sys.

Public names: `TrueApp`, `FalseApp`, `Env`, `PrintEnv`, `Id`, `Whoami`, `Uname`, `DateApp`, `Uptime`, `Hostname`, `Dmesg`, `Free`, `Df`, `Mount`, `Clear`, `Which`, `Help`, `FileApp`, `Wasm`, `Thsh`, `TestApp`, `Expr`.
