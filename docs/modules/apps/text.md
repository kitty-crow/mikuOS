# apps/text

Text commands consume guest standard input or selected files and emit their results through the current output descriptor. Each command owns its argument syntax, matching rules and exit status; binary encoders operate on byte arrays.

Public names: `Echo`, `Printf`, `Tail`, `Wc`, `Grep`, `Sort`, `Uniq`, `Cut`, `Tr`, `Sed`, `Tee`, `Seq`, `Yes`, `Base64`, `Strings`.
